회원가입 없는 정보보안 점검 도구 · 단일 HTML 실행 지원

의심스러운 링크와 메시지, 열기 전에 바로 점검하세요

LeakGuard는 로그인이나 계정 생성 없이 URL 구조 위험 신호, 비밀번호 유출 여부(HIBP k-Anonymity), 피싱·스미싱 의심 문구를 빠르게 점검할 수 있는 한국어 보안 웹 애플리케이션입니다.

임의 결과 생성 · 과장 금지

API 키가 필요한 Google Safe Browsing과 Gemini AI는 정적 HTML 환경에서 미연동(조회 불가)으로 명확히 안내하며, 어떤 검사도 안전을 100% 보장하지 않습니다.

최소 전송 보안 원칙

원본 비밀번호와 전체 해시는 절대 외부 전송·저장하지 않으며, URL 및 피싱 분석 입력도 기기 내에서만 정적·규칙 기반으로 처리합니다.

비밀번호 유출 및 안전성 검사

원본 비밀번호와 전체 SHA-1 해시는 서버·저장소·로그에 절대 전송되거나 기록되지 않습니다. Web Crypto API로 계산한 SHA-1 해시 앞 5자리만 Have I Been Pwned Range API에 전달해 브라우저에서 직접 대조합니다(k-Anonymity).

Web Crypto API 미지원 환경
현재 브라우저 컨텍스트에서는 SHA-1 해시 계산이 제한되어 외부 유출 DB는 조회 불가입니다. 로컬 구조·패턴 분석만 이용할 수 있습니다.

피싱·스미싱 의심 메시지 검사

문자(SMS), 메신저, 이메일 본문을 붙여넣으면 브라우저 내에서 규칙 기반으로 사칭 문구, 인증번호 요구, 긴급 압박 표현, 포함된 URL 구조를 즉시 검사합니다.

규칙 기반 로컬 검사 모드 (Gemini AI 미연결 · 조회 불가)
이 검사는 인공지능(AI)이 아닌 키워드·정규식·URL 구조 규칙에 기반한 로컬 추정 검사입니다. 입력한 메시지는 외부 서버로 전송·저장되지 않으며 포함된 링크에도 직접 접속하지 않습니다.

GitHub 업로드용 소스 파일 다운로드

정적 HTML · GitHub Pages 호환

현재 LeakGuard 앱을 초기화한 깨끗한 index.html과 README.md, .gitignore 파일을 바로 내려받아 GitHub 저장소에 업로드할 수 있습니다. (입력한 검사 기록·비밀번호는 포함되지 않습니다.)

GitHub 웹 업로드 및 Pages 배포 순서
  1. 위 버튼으로 leakguard-github.zip(압축 해제 후 업로드) 또는 index.html + README.md를 다운로드합니다.
  2. GitHub 저장소에서 Add file → Upload files를 눌러 루트 경로에 업로드하고 커밋합니다.
  3. 웹사이트로 바로 배포하려면 저장소 Settings → Pages에서 Branch를 main / /(root)로 지정합니다.

개인정보 처리 안내

  • 회원가입 불필요: 이름, 이메일, 전화번호 등 개인 식별 정보를 수집하지 않으며 즉시 모든 기능을 이용할 수 있습니다.
  • 비밀번호 원문 비전송·비저장: 브라우저 Web Crypto API로 계산한 SHA-1 해시 앞 5자리만 HIBP Range API에 전달하며 전체 해시와 원문은 저장·로그하지 않습니다.
  • URL 및 메시지 비접속·비보관: 입력한 URL이나 메시지 내 링크에 직접 접속하지 않으며 메시지 원문을 서버나 저장소에 보관하지 않습니다.
  • 안전 보장 불가 안내: 모든 검사는 보조 진단 도구이며 알려진 위협 목록에 없더라도 100% 안전을 보장하지 않습니다.

기능별 실제 동작 vs 조회 불가(미연동) 범위

URL 로컬 정적 구조·사칭 패턴 검사 실제 동작 (로컬)

HTTPS 여부, IP 직접 연결, Punycode, @ 기호 혼동, 단축 URL, 사칭 도메인 패턴을 오프라인에서도 분석합니다.

Google Safe Browsing 외부 악성 URL DB 조회 불가 (미연동)

API 키 보호를 위한 백엔드 서버가 없는 단일 HTML 환경이므로 연동하지 않았으며 조회 불가로 명시합니다.

비밀번호 강도 분석 & HIBP k-Anonymity 실제 동작 (인터넷 필요)

로컬 취약 패턴 분석은 오프라인에서도 동작하며, HIBP 유출 조회는 인터넷 연결 시 앞 5자리 해시만 대조합니다.

피싱·스미싱 메시지 검사 규칙 기반 동작 (AI 미연동)

Gemini AI가 아닌 브라우저 내 규칙·키워드·URL 구조 탐지 엔진만 동작합니다.
